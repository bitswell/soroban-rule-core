# Extracted evaluator (generated)

`RuleEval.lean` is the Lean translation of `crates/rule-eval`, generated by
`tools/extract.sh` with the Charon and Aeneas that `flake.nix` pins: Charon
translates the crate to LLBC, Aeneas translates the LLBC to Lean
(`-backend lean -warnings-as-errors`). Do not edit it by hand; change the Rust
and re-run the script.

CI (`.github/workflows/extraction.yml`) re-runs the extraction
(`tools/extract.sh --check`) and fails if the result differs from the file
here. `RuleCore/Equiv/` proves that this code agrees with the chain vocabulary
of `RuleCore/Vocab/`, and `RuleCore/Theorems/Extracted.lean` carries the
model's theorems over to it; `formal/README.md` lists them.

Aeneas logs a notice that the crate "contains extracted external, unknown
definitions". It refers to `core::num::usize::BITS`, the constant read by the
compile-time assertion in `crates/rule-eval/src/lib.rs` (`rule_eval.«_»`
here). Aeneas's Lean library defines it as `core.num.Usize.BITS`, and the file
declares no opaque definitions.
